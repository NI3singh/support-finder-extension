# Extension icons

The build expects four PNG icons in this directory:

- `icon-16.png` (16×16)
- `icon-32.png` (32×32)
- `icon-48.png` (48×48)
- `icon-128.png` (128×128)

These are referenced by `manifest.json`. To keep the source repo lean we
don't ship binary art. Replace these with your own brand icons before
publishing to the Chrome Web Store.

For development, you can generate simple placeholder icons with any image
editor (a flat colored square is fine) or use a tool like
`https://favicon.io` to produce all four sizes.
